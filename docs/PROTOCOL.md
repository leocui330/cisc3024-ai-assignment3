# Experimental protocol

The protocol was set before fitting and before scoring the official test partition.

- Data: UCI Optical Recognition of Handwritten Digits. Use all 3,823 official training records to define three stratified 3,058 fit / 765 validation splits (seeds 11, 22, 33). Keep the official 1,797-image writer-disjoint test set for the evaluate command. UCI split metadata describes 30 training writers and 13 different test writers. Writer IDs are unavailable for stratifying the internal validation split.
- Input: 64 row-major 8 × 8 block counts per digit, divided by 16. Center using the fit partition's mean (after corruption when applicable). Apply that mean to validation and test images.
- Conditions: clean fit gallery and contaminated fit gallery, each evaluated on clean unseen writers. For contamination, uniformly choose 30% of fit images, then independently choose 35% of the cells in each selected image and replace them with randomly assigned 0 or 1. Use `default_rng(seed + 1000)`. Validation and test are unmodified. Pair all methods on identical input and labels.
- Recognition: Euclidean one-nearest-neighbor with gallery of fit-set projections. Ties go to the first index in original fit-data order. Compare raw pixels (64 coordinates), ordinary PCA, PCA-L1, RSPCA (no graph term), RSMPCA (no sparsity term), and RSSPCA. All projected methods use 16 coordinates. This rank was fixed before testing.
- RSSPCA selection: search a shared 3 × 3 grid, eta_1 in {0.01, 0.1, 1} and eta_2 in {0.1, 1, 10}, independently per seed/condition. Maximize validation accuracy and break ties by smaller eta_1 then smaller eta_2. Ablations hold the other coefficient at its chosen RSSPCA value. They represent matched deletions, with no separate retuning.
- Numerical rule: train-set ordinary PCA initialization, Algorithm 1 from Wang et al. (2025), relative L1 score change threshold 1e-4 and up to 100 iterations per loading. Solve Eq. (32) through an equivalent symmetric system to allow zero coefficients. Use the paper's cumulative deflation on the current residual.
- Ordering: select on the training partition, seal code and selected model artifacts using SHA-256, and then perform a single final held-out evaluation without retraining. Preserve per-record predictions and pre-test selections.
- Outcomes: test accuracy and macro-F1 as percentages, separately for each condition and seed. Summarize means and sample SD over three shared-test runs. Report paired accuracy changes for RSSPCA vs PCA and its matched deletions. Supplement classification scores with mean per-loading L1 norm, graph roughness, effective support and iteration counts. Illustrate seed 11 and the contaminated condition, fixed in advance. Seed variation measures sensitivity to fit/validation partitions and contamination, not independent test-sample uncertainty.
